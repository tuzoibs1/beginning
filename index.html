Git Commands Reference

Your comprehensive guide to Git commands

Basic Commands

git -v

Check Git version

git init

Initialize a new Git repository

git add

Add files to staging area

git commit -m ""

Commit changes with a message

Remote Operations

git push origin branchName

Push changes to remote branch

git remote add origin url

Add new remote repository

git remote -v

View remote repositories

git pull origin branchname --allow-unrelated-histories

Pull with unrelated histories (fix for merge conflicts)

git push -f origin master

Force push to remote (use with caution!)

Branch Management

git checkout branchName

Switch to existing branch

git branch

List branches and show current branch

git branch name-branch

Create a new branch

git merge branch-name

Merge branch into current branch

git branch -D master

Delete a branch (force delete)

git branch -m master

Rename current branch to master

Advanced Operations

git reset HEAD --hard id

Reset to specific commit (destructive - use with caution!)

git rm -r folder-name

Remove folder/files from repository

git checkout --orphan latest_branch

Create orphan branch (no history)

git add -A

Add all files (including deletions)

git commit -am "commit message"

Add and commit all changes in one step

Configuration

git config credential.helper store

Store credentials to avoid repeated login prompts
